The routes run on a thread of a task executor (normally Spring Boot's `applicationTaskExecutor`), not on the servlet
thread that received the request. To run them with the context of the request, for example so that with Micrometer
Tracing the spans of the route belong to the trace of the HTTP request instead of starting a new one, enable Spring
Boot's context propagation for its task executors:

[source,properties]
----
spring.task.execution.propagate-context=true
----

It needs `io.micrometer:context-propagation`, which comes with Micrometer Tracing (for example with
`spring-boot-starter-opentelemetry`). It carries over any context registered with context propagation, such as the
Spring Security context or the MDC when their accessors are registered. It applies to the executors that Spring Boot
builds; an executor bean that you build yourself needs a `ContextPropagatingTaskDecorator` of its own.
